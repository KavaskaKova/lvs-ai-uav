# lvs-ai-uav

Аддон изменяет поведение AI самолетов в аддоне LVS. 
Теперь БпЛА из разных аддонов из мастерской влетают в цель как камикадзе. 

P.S: Добавил поддержку FPV дронов, теперь они тоже влетают в цель как камикадзе. 

!!! Важно понимать что этот скрипт меняет поведение ВСЕХ самолетов и БпЛА самолетного типа, а так же вертолетов и FPV дронов. Так что даже обычные самолеты будут в вас влетать как камикадзе !!!
